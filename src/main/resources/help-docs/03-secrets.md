# 시크릿: 현황, 키·노출 위치, 확인 대기열

시크릿 기능은 GitHub·AWS 등에서 키(시크릿) 후보를 찾고, 위치별로 확인한 뒤 대응까지 이어 가는 기능입니다.

## 시크릿 현황 보기
사이드바 "시크릿" > "현황"에서 지금 할 일을 봅니다.
- 카드: "확인 필요"(위치 수), "대응 중"(대응 건 수), "재검사 대기".
- 할 일 목록: "대상", "확인할 이유", "담당자", "다음 행동" 열이 있고, 다음 행동에는 "대응 생성", "발견 검토", "내용 확인" 등이 나옵니다.
- "검사 대상 설정"과 "최근 검사 상태"("실행 상세", "원인·복구 확인") 영역도 있습니다.
- "검사할 연결을 등록하세요"가 보이면 아직 연결이 없습니다. "연결 관리" 또는 "스캔 요청" 버튼으로 시작합니다.
- "조회 기준이 변경됐어요"가 보이면 "최신 현황 조회"를 누릅니다.

## 키·노출 위치에서 키 찾기
사이드바 "시크릿" > "키·노출 위치"에서 발견된 키 목록을 봅니다.
1. 필터("발견 플랫폼", "자원 환경", "키 발급 서비스", "기록 종류", "할 일", "키 구성", "유효성", "위험도")로 범위를 좁힙니다. "필터 초기화"로 되돌립니다.
2. 표의 "키", "확인할 이유", "구성·검증", "열람 위치", "최근 발견", "다음 행동"을 확인합니다. "이전"/"다음"으로 페이지를 넘깁니다.
3. 키를 누르면 키 상세 화면이 열립니다.

조회에 실패했다고 해서 탐지 결과가 0개라는 뜻은 아닙니다.

## CSV로 내보내기
1. 키·노출 위치에서 필터를 원하는 조건으로 맞춥니다.
2. "마스킹 CSV 내보내기"를 누릅니다. 준비되는 동안 "CSV 준비 중…"이 표시됩니다.
3. 한 번에 10,000개까지 내보낼 수 있습니다. 넘으면 조건을 좁혀 달라는 안내가 나옵니다.

## 키 상세 화면
- "키 정보"에서 "발급자", "키 유형", "구성", "심각도", "첫 발견", "최근 발견"을 봅니다.
- "발견 위치", "판단 근거", "사용 이력" 탭으로 같은 키의 위치들을 비교합니다.
- 위치마다 "노출 판단", "공개 여부", "보관 정책", "유효성", "담당자"가 표시됩니다.
- 대응 건이 없으면 "보관·공유 판단", 있으면 "판정 근거 확인" 버튼으로 위치 확인 화면에 갑니다. "현재 대응·조치"는 연결된 대응 건을 엽니다.

## 키 유효성 확인하기
1. 키 상세의 "확인할 발견 위치"에서 위치를 고릅니다.
2. "유효성 확인"을 누릅니다.
3. "이 위치의 키 인증을 확인할까요?"에서 "확인 요청"을 누릅니다.

이 확인은 키로 인증이 되는지만 봅니다. 키를 바꾸거나 폐기하지 않습니다. 권한이 없으면 "보안 담당자에게 확인 요청"이 보입니다.

## 확인 대기열
"확인 대기열"은 위치별로 판단이 필요한 작업을 모은 곳입니다. 키·노출 위치나 현황의 다음 행동에서 들어갑니다.
- 필터: "할 일", "발견 플랫폼", "자원 환경", "키 발급 서비스", "담당 범위", "위험도", "키 유효성".
- 표의 다음 행동: "위치 근거 확인", "대응 건 확인", "검사 대상 설정 열기".
- 위쪽 "추가 조사", "자격증명 여부 확인" 버튼으로 조사 과제와 실키 경고 목록에 갑니다.

## 위치 확인에서 결정 저장하기
1. "결정" 영역의 "가능한 결정 선택"에서 하나를 고릅니다: "노출 확인 및 조치 요청", "보관 허용 확인", "선택 근거 오탐 교정", "추가 조사 요청".
2. "탐지 근거 선택", "결정 사유", "근거 참조"(티켓이나 정책 번호만)를 채웁니다.
3. "추가 조사 요청"이면 "부족한 근거", "조사 담당자", "확인 기한"(90일 이내)도 채웁니다.
4. "이 위치의 현재 근거와 저장 결과를 확인했어요."를 체크하고 "결정 저장"을 누릅니다.

이미 노출이 확인된 키라면 체크 후 "현재 대응 건에 연결"을 누릅니다. 권한이 없으면 "보안 담당자의 확인이 필요해요."가 보입니다.

## 추가 조사 진행하기
1. 확인 대기열의 "추가 조사"에서 과제를 엽니다. "상태"와 "담당 범위"로 목록을 거를 수 있습니다.
2. "담당자·기한 지정"에서 바꾸고 "담당·기한 저장"을 누릅니다.
3. "조사 근거 추가"에서 근거를 넣고 "근거 추가"를 누릅니다.
4. 끝나면 "조사 종료"에서 "확인된 후속 결과"를 고르고 체크한 뒤 "조사 종료"를 누릅니다.

조사를 종료해도 대응 건이 해결되지는 않습니다.

## 실키 경고 처리하기
1. "자격증명 여부 확인"에서 경고를 엽니다.
2. "조사 담당·기한"을 정하고 "담당·기한 저장"을 누릅니다.
3. 내용을 확인했다면 "경고 인지 기록"에서 "확인 내용"을 고르고 "인지 기록"을 누릅니다. 인지 기록만으로 경고가 닫히지는 않습니다.
4. 닫을 근거가 있으면 "근거에 따라 경고 종료"에서 "종료 근거"를 고르고 체크한 뒤 "근거 확인 후 종료"를 누릅니다.
