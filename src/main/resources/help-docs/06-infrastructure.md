# 인프라 보안: 컴플라이언스, 신원·권한, 런타임, IaC

## 컴플라이언스 화면
사이드바 "인프라 보안" > "컴플라이언스"는 클라우드 설정을 규제 기준으로 점검합니다.
- "점검 대상"과 "보고서"("통합", "ISMS-P", "ISO 27001", "CSAP")를 골라 결과를 봅니다.
- 위쪽 버튼: "새로고침", "감사 보고서"(결과가 있을 때), "결과 가져오기"와 "새 점검"(관리자만).
- 아래에 "자동 점검", "최근 점검 결과", "점검 이력" 영역이 있습니다.

## AWS 점검 대상 등록하기
1. "AWS 점검 연결"의 "대상 등록"에서 "표시 이름", "AWS 계정 ID", "점검 Role ARN", "기본 리전"을 입력합니다.
2. "AWS 연결 확인"을 누릅니다.
3. "자동 점검 대상으로 활성화"를 누릅니다.

연결 확인과 활성화가 끝나기 전에는 "새 점검" 버튼이 꺼져 있습니다.

## 컴플라이언스 점검 실행하기
1. "새 점검"(처음이면 "첫 점검 시작")을 누릅니다.
2. "AWS 컴플라이언스 점검" 창에서 "점검 환경"("운영"/"개발"), "점검 범위"("전체 점검", "서비스 선택", "Check 선택"), "AWS 리전"을 고릅니다.
3. "점검 시작"을 누릅니다.
4. "자동 점검" 영역에서 진행을 보고, 끝나면 "결과 보기"를 누릅니다. 진행 중에는 "취소"할 수 있습니다.

다른 곳에서 만든 점검 결과(JSON, 8MB까지)는 관리자가 "결과 가져오기"로 넣을 수 있습니다. 이때 "가져올 환경"을 고릅니다.

## 신원·권한
아직 준비 중인 화면입니다. "이 화면은 다음 단계에서 만들어요."가 표시됩니다.

## 런타임 보안
실행 중인 워크로드에서 생긴 이벤트를 탐지합니다. "탐지 전용"이라 Finding을 자동으로 차단하지 않습니다.
- "탐지 결과"는 Namespace, 검토 상태("미확인"/"확인함"), 규칙으로 거를 수 있습니다.
- "Sensor 상태" 표에서 센서 연결을 확인합니다. "연결된 런타임 센서가 없어요"가 보이면 센서가 아직 없습니다.

Finding 조사 내용 저장하기:
1. 탐지 결과에서 Finding을 누릅니다.
2. "조사 정보"에서 "검토 상태", "조치 상태", "판정", "메모"를 입력합니다.
3. "조사 내용 저장"을 누릅니다.

## IaC 보안
인프라 코드(Terraform 등) 변경이 만드는 공격 경로와 State·드리프트를 봅니다. 매일 03:00에 수집하고 PR마다 분석합니다.
- 지표: "1등급까지 열린 경로", "실제 드리프트", "State 속 실제 시크릿", "plan 전 검사 위반 (main 기준)".
- "지금 열린 공격 경로"의 줄을 누르면 "공격 경로 상세"가, "PR 검사 결과"의 줄을 누르면 PR 검사 결과가 열립니다.
- "plan 전 검사", "State·드리프트", "할 수 있는 조치", "검사 주기와 상태" 영역도 있습니다.
- "지금 점검"으로 바로 점검하고, "규칙 보기"로 검사 규칙을 봅니다.
