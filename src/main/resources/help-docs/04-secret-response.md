# 시크릿: 대응 관리

대응 건은 노출된 키를 실제로 바꾸거나 없애는 작업을 추적하는 단위입니다. 단계는 "신규" → "조치 중" → "재검사 대기" → "해결" 순서로 진행됩니다.

## 대응 건 만들기
대응 관리 목록에는 만들기 버튼이 없습니다. 대응 건은 다음 순서로 만들어집니다.
1. 키·노출 위치 또는 확인 대기열에서 위치를 열어 위치 확인 화면으로 갑니다.
2. "가능한 결정 선택"에서 "노출 확인 및 조치 요청"을 고릅니다.
3. 근거와 사유를 채우고 확인 체크 후 "결정 저장"을 누르면 대응 건이 새로 만들어지거나 기존 대응 건에 연결됩니다.

## 대응 건 목록 보기
사이드바 "시크릿" > "대응 관리"에서 목록을 봅니다.
- "조회 범위"에서 "현재 대응 건" 또는 "종료·교정 이력"을 고릅니다. "단계", "위치 배정", "담당 범위" 필터도 있습니다.
- 표: "대응 건·키", "단계", "조정 담당자", "허용된 위치", "최근 변경", "다음 작업".
- "대응 열기"를 누르면 대응 상세가 열립니다.
- "조건에 맞는 대응 건이 없어요."가 보이면 "확인 대기열 보기"로 이동해 판단할 위치를 확인합니다.

## 대응 상세 화면
"현재 작업", "위치별 현황", "재검사·해결", "활동 기록" 탭이 있습니다. "최신 상태 조회"로 새로 고치고, "← 대응 목록으로 돌아가기"로 목록에 돌아갑니다.

## 담당자 지정·변경하기
1. 위치 하나의 담당자는 "이 위치의 실제 조치 담당자 지정·변경"을, 대응 건 전체는 "대응 진행 관리자 변경"을 엽니다.
2. "새 담당자"에서 사람이나 팀을 고르거나 "지정 해제"를 고릅니다.
3. "담당자 저장"을 누릅니다.

권한이 없으면 "담당을 바꿀 권한이 없어요."가 보입니다.

## 조치 기록하기
1. "현재 작업" 탭의 "작업할 위치"에서 위치를 고릅니다.
2. "외부 조치 기록"에서 "수행한 작업"을 고릅니다: "키 교체", "키 폐기", "노출 위치에서 제거", "권한 축소".
3. "실제 수행 시각 (KST)"과 "티켓·변경 참조"를 입력하고 체크한 뒤 "외부 조치 저장"을 누릅니다.
4. 기록을 다 했으면 "조치 기록 마침"에서 체크하고 "조치 기록 마침"을 누릅니다.

"보조 체크리스트"의 "체크 기록"/"체크 해제"는 선택 사항입니다. 키를 실제로 바꾸는 일은 Logssey 밖(각 서비스 콘솔)에서 하고, 여기에는 한 일을 기록합니다.

## 재검사하고 해결하기
1. "재검사·해결" 탭을 엽니다. "해결 조건", "위치 재검사", "키 폐기·교체" 영역이 있습니다.
2. "위치별 후속 작업"에서 "작업 위치"를 고르고 체크한 뒤 "이 위치 재검사 요청"을 누릅니다.
3. 재검사에서 키가 다시 발견되면 "이 위치 추가 조치"로 조치를 더 기록합니다.
4. 조건을 채웠으면 "해결 확인"에서 "확인 수준"을 고르고 체크한 뒤 "해결 확인 저장"을 누릅니다.

## 조치 없이 종료하기 (예외·종료 처리)
- "위험 수용": 정해진 기간 동안 위험을 받아들이고 종료합니다.
- 오탐이었다면 "오탐 교정·담당 이관"에서 "종료 사유"를 고르고 "교정 종료 저장"을 누릅니다.
- 다른 팀으로 넘길 때는 "이관·인수 근거 제출"에서 "이관 검토 요청"을 누릅니다. 다른 검토자가 "이관 근거 검토"에서 "이관·인수 근거 승인" 또는 "근거 반려"를 고릅니다.
