# 시크릿: 연결 관리, 스캔, 키 형식 등록

## 연결 추가하기
연결은 Logssey가 키를 찾을 곳(GitHub 저장소, AWS 계정)을 등록하는 것입니다. 사이드바 "시크릿" > "연결 관리"에서 합니다.
1. "+ 연결 추가"를 누르고 "플랫폼"(GitHub 또는 AWS)을 고른 뒤 "연결 이름"을 입력합니다.
2. GitHub는 "GitHub App 인증" 칸("App ID", "Installation ID", "App 개인 키")을 채웁니다. AWS는 서버 IAM 역할로 인증하므로 키를 입력하지 않습니다.
3. "연결 만들기"를 누르면 "연결을 만들었어요. 검사 대상을 선택하세요."가 나옵니다.
4. 검사 대상을 정합니다. GitHub는 "저장소 선택"과 브랜치를 고르고, 필요하면 "폴더"를 적습니다(비우면 저장소 전체). "+ 검사 대상 추가"로 더 넣을 수 있습니다. AWS는 "조회할 메타데이터"와 리전을 고릅니다. 다 됐으면 "검사 대상 저장"을 누릅니다.
5. "연결 활성화"를 누릅니다.
6. 목록에서 "연결 테스트"를 눌러 연결을 확인합니다.

연결 정보 입력은 이 화면의 입력 칸에만 하세요. 도움말 챗봇이나 다른 곳에 키를 붙여 넣지 마세요.

## 연결 상태 읽기
"연결 테스트" 결과는 "연결 확인됨", "연결 확인 실패", "연결 확인 불가", "연결 테스트 전" 중 하나로 보입니다. 목록 위의 상태 필터("전체 상태", "활성" 등)로 거를 수 있습니다.

## 연결 설정 바꾸기
목록의 "설정"을 누르면 "검사 대상", "연결 정보", "인증 정보" 탭이 열립니다. "인증 정보" 탭에서 "인증 교체", "인증 해제", "인증 정보 삭제"를 할 수 있습니다. 인증 정보 삭제는 7일 동안 되돌릴 수 있고 그 뒤 지워집니다. 목록의 "검사 대상", "키 검증 설정" 버튼으로 각 설정에 바로 갈 수도 있습니다.

## 스캔 시작하기
방법 1: "연결 관리" 목록에서 연결 줄의 "스캔 요청"을 누르고 "스캔 시작"을 누릅니다.

방법 2: "스캔 이력"이나 "키·노출 위치"의 "스캔 요청" 버튼을 누릅니다.
1. "승인된 범위를 검사할까요?" 창에서 "검사할 연결"을 고릅니다.
2. "스캔 등록"을 누릅니다. 그만두려면 "취소"를 누릅니다.

## 스캔 이력 보기
사이드바 "시크릿" > "스캔 이력"에서 검사 실행 기록을 봅니다.
- 필터: "실행 유형", "실행 상태", "발견 플랫폼", "연결", "요청 시작 (KST)", "요청 종료 (KST·미포함)".
- 표: "실행", "연결", "실행 상태", "범위 커버리지", "수집 항목", "시각", "소요 시간".
- "상세 보기"를 누르면 스캔 상세에서 부분 실패 범위 등을 확인할 수 있습니다.

## 키 형식 등록하기
회사 내부에서 만든 키처럼 기본 규칙에 없는 키 모양을 등록해 스캔에 추가합니다. 등록과 삭제는 관리자만 할 수 있고, 미리보기와 샘플 시험은 누구나 할 수 있습니다.
1. 사이드바 "시크릿" > "키 형식 등록"의 "새 형식"에 이름(예: 사내 RIK 키)과 접두어(예: rik_)를 입력합니다.
2. "이 값만으로 로그인·호출이 되나요?"에 "네, 비밀값이에요" 또는 "아니요, 식별자예요"로 답합니다.
3. "자동으로 만들어진 규칙"을 확인합니다. "샘플로 시험해 보기"로 미리 시험할 수 있으며 이때는 저장되지 않습니다. 샘플에는 실제 키 대신 만든 값을 쓰세요.
4. "형식 등록"을 누릅니다.

지우려면 "등록된 형식"에서 "삭제"를 누릅니다. "등록한 형식으로 찾은 키"의 "지금 스캔"은 수집기에 공유된 Notion 페이지를 검사합니다.
