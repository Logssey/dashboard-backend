# 시작하기: 로그인과 화면 구성

## 로그인하기
1. 로그인 화면에서 "아이디"와 "비밀번호"를 입력합니다. 두 칸을 모두 채워야 "로그인" 버튼을 누를 수 있습니다.
2. "로그인"을 누르면 "로그인 중…"이 표시되고, 성공하면 통합 현황 화면(또는 처음 열려던 화면)으로 이동합니다.
3. 회원가입 기능은 없습니다. 관리자가 미리 만든 계정으로 로그인합니다.

GitHub 조직 로그인이 설정된 경우에만 "GitHub로 로그인" 버튼이 보입니다. GitHub 로그인이 실패하면 버튼 위에 오류 문구가 나옵니다.

## 로그인이 안 될 때
- 아이디나 비밀번호가 틀리면 서버가 알려 주는 문구가 표시됩니다.
- "로그인하지 못했어요. 잠시 후 다시 시도해 주세요."가 보이면 잠시 뒤 다시 시도합니다.
- "서버에 연결하지 못했어요. 백엔드가 켜져 있는지 확인해 주세요."가 보이면 서버가 꺼져 있는 것이므로 운영 담당자에게 알립니다.

## 로그아웃하기
화면 오른쪽 위 상단 바의 "로그아웃" 버튼을 누르면 로그인 화면으로 돌아갑니다.

## 화면 구성
- 왼쪽 사이드바("보안 워크스페이스")에 네 가지 메뉴가 있습니다: "통합 현황", "시크릿", "인프라 보안", "취약점 관리".
- "시크릿"을 열면 "현황", "키·노출 위치", "대응 관리", "연결 관리", "스캔 이력", "키 형식 등록"이 보입니다. "키·노출 위치" 옆 숫자는 확인이 필요한 위치 수입니다.
- "인프라 보안"을 열면 "컴플라이언스", "신원·권한", "런타임 보안", "IaC 보안"이 보입니다.
- "취약점 관리"를 열면 "요약", "Finding 목록", "워크로드", "스캔"이 보입니다.
- 상단 바에는 현재 위치("워크스페이스 > 화면 이름"), 사용자 이름, "로그아웃" 버튼, 도움말 버튼이 있습니다.
- 없는 주소로 들어가면 통합 현황으로 이동합니다.
- 휴대폰처럼 좁은 화면에서는 왼쪽 위 메뉴 버튼을 눌러 사이드바를 엽니다.

## 도움말 챗봇 쓰기
- 상단 바의 "?" 도움말 버튼을 누르면 오른쪽에 사용법 도우미가 열립니다.
- 도우미는 이 사용 가이드 문서만 보고 답합니다. 실제 키, 탐지 결과, 대응 건, 계정 정보는 볼 수 없습니다.
- 질문에 키, 토큰, 비밀번호를 넣지 마세요. 키처럼 보이는 값이 있으면 질문을 보내지 않습니다.
- 질문은 한 번에 500자까지, 1분에 5번, 하루 40번까지 할 수 있습니다.
