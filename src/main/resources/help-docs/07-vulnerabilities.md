# 취약점 관리 사용법

취약점 관리는 이미지와 패키지의 알려진 취약점(CVE)이 실제 코드에서 닿을 수 있는지 판정해 보여 줍니다.

## 요약 화면
- "집계 기준"에서 "운영 중 이미지 기준" 또는 "최신 빌드 기준"을 고릅니다.
- "상태 × 심각도" 표의 칸을 누르면 그 조건의 Finding 목록으로 갑니다.
- 판정 상태는 "도달 가능", "미확인", "사람 확인 필요", "분석 대상 아님", "안전"입니다.
- "판정 흐름", "먼저 고칠 것", "배포 상태(L1)", "스캔 정보" 영역도 있습니다.

## Finding 목록에서 찾기
1. "상태", "심각도", "검토 상태", "배포 상태", "실행(L3)" 필터와 "CVE 검색" 칸으로 좁힙니다.
2. 목록 아래 "더 보기"로 더 불러옵니다.
3. 줄을 누르면 상세가 열려 "근거"(앱 코드 사실, 확인 범위, 호출 경로), "적용 규칙", "수정 버전", "업그레이드 제안", "검토 이력"을 볼 수 있습니다.

## Finding 검토 저장하기
1. Finding 상세에서 "확정" 또는 "잠정"을 고릅니다.
2. "판정 선택"에서 판정을 고르고 "메모"를 적습니다.
3. "검토 저장"을 누릅니다.

"저장 권한이 없거나 로그인이 끝났어요. 다시 로그인해 주세요."가 보이면 다시 로그인하거나 권한을 확인합니다.

## 워크로드 확인하기
- 카드: "실행 중 워크로드", "스캔한 digest와 일치", "스캔 없음 · 불일치".
- 표: "워크로드", "앱", "이미지", "파드", "배포", "스캔 연결".
- 실행 중인 이미지가 스캔한 이미지와 다르면 줄의 "스캔 요청"으로 새 스캔을 요청합니다. "새로 고침"으로 최신 상태를 봅니다.

## 새 취약점 스캔 요청하기
1. "스캔" 화면에서 "새 스캔"을 누릅니다.
2. "대상 유형"에서 "이미지 digest"("이미지 저장소", "digest") 또는 "레포 커밋"("레포", "커밋 SHA", "레포 안 경로 (선택)")을 고릅니다.
3. "앱"을 고릅니다. 기본값은 "설정의 레포·저장소로 정하기"입니다.
4. "단계"에서 "SBOM 생성 · CVE 대조 (항상)"는 늘 켜져 있고, "L1 배포 확인", "L2 판정"을 추가로 고를 수 있습니다. "L3 실제 호출 (계획)"은 아직 쓸 수 없습니다.
5. "스캔 요청"을 누릅니다.

진행 중인 스캔은 10초마다 자동으로 새로 고쳐집니다. "스캔" 화면에는 "스캔 이력"과 "CI 검사" 탭이 있습니다.

## 규칙 보기
규칙 화면은 판정에 쓰는 규칙을 보여 줍니다. "평가 순서"는 위에서부터 처음 맞는 줄이 판정이 됩니다. "쓰는 사실", "취약 함수", "적용 Finding"도 함께 볼 수 있습니다.
