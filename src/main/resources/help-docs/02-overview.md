# 통합 현황 사용법

통합 현황(제목 "통합 대시보드")은 로그인 후 처음 보이는 화면으로, 여러 보안 기능의 위험을 한곳에 모아 보여 줍니다.

## 환경 고르기
화면 위쪽 선택 상자에서 "전체 환경", "운영 환경", "개발 환경" 중 하나를 고르면 모든 카드와 표가 그 환경 기준으로 바뀝니다. 단, "보안 점수" 카드와 "자산별 보안 점수" 표, "보안 기능별 반영 현황"의 "감점(운영)" 열은 늘 운영 환경 기준입니다. 옆에 "선택 환경의 조회 결과 · 최근 관측 …"으로 기준 시각이 표시됩니다.

## 카드 읽는 법
- "지금 확인할 위험": 아직 검토하지 않은 Critical 건수와 "전체 탐지", "확인·조치 필요", "연결 자산" 수를 보여 줍니다. "위험 확인하기" 버튼을 누르면 아래 우선순위 표의 첫 줄로 이동합니다.
- "보안 점수": 운영 환경 기준 100점 만점 점수로, 환경 선택과 관계없이 운영 환경만 계산합니다. 자산마다 가장 큰 위험 하나만 깎고(Critical 74~99점, High 48~73점, Medium 22~47점, Low는 깎지 않음), 중요한 자산일수록 크게 반영합니다. 아직 평가하지 못한 자산은 점수에서 빼고 "평가 범위 N%"로 따로 보여 주므로, 평가 범위가 낮으면 점수가 높아도 안전하다는 뜻이 아닙니다. 평가된 자산이 하나도 없으면 "—"로 표시됩니다.
- "자산별 보안 점수" 표: 자산마다 "평가됨", "평가 끊김", "평가 안 됨" 상태와 점수, 감점을 정한 위험 하나를 보여 줍니다. "보안 기능별 반영 현황" 표의 "감점(운영)"은 그 기능의 위험만으로 깎이는 점수이고, 기능별 감점을 더해도 전체 감점과 같지 않습니다.
- "위험은 어떻게 변했을까요?": 최근 7일 동안 탐지 건수가 어떻게 변했는지 그래프로 보여 줍니다.
- "연결된 자산": 클라우드 제공자별 연결 자산 수입니다.

## 시크릿 대응 집계
"통합 조회 범위의 시크릿 대응 N건을 포함해요."가 보이면 시크릿 대응 건이 집계에 들어간 것이고, "시크릿 현황" 링크로 이동할 수 있습니다. "시크릿 대응 건은 조회 권한이 없어 집계에 포함하지 않았어요."가 보이면 내 계정에 시크릿 조회 권한이 없는 것입니다.

## 먼저 확인할 항목 표
"먼저 확인하면 좋아요" 표에는 "심각도", "탐지 내용 / 자산", "환경", "담당 팀", "상태"가 나옵니다.
1. 표에서 항목을 누르면 오른쪽에 "탐지 상세" 패널이 열립니다.
2. 패널에서 "영향받는 자산", "환경", "담당 팀", "보안 영역", "탐지 근거", "권장 대응"을 확인합니다.
3. "닫기"를 누르면 패널이 닫힙니다.

세부 정보가 하나도 없으면 "정보 없음"이 표시됩니다. 검토 상태를 저장하는 기능은 아직 준비 중이라, 상태 변경은 각 보안 기능 화면에서 합니다.

## 비어 있거나 오류가 날 때
- "검토할 항목이 없어요": 선택한 환경에 확인할 탐지가 없습니다.
- "데이터를 불러오지 못했어요.": 잠시 뒤 새로 고침합니다.
